```markdown
# Field notes: AMD Cezanne APU + NVIDIA Turing (RTX 2080 Ti)

Configuration verified on: BESSTAR B550 / Ryzen 7 5700G / RTX 2080 Ti (10DE:1E07),
macOS 15.8.1 (24H32), OpenCore 1.0.9, SMBIOS iMacPro1,1, csr 0x0A43.

## Display bring-up
- Desktop comes up on the 2080 Ti with default driver settings; the iGPU
  (NootedRed) remains loaded for video decode/encode but is not used for display.
- BIOS must have **Above 4G Decoding = Enabled** and **Re-Size BAR Support = Auto
  (or Enabled)**. Without Above 4G the driver stops at NVRM-XNU BAR1 placement
  (`no 64-bit window in the host bridge's _CRS (not an Intel CPU)`) and reboots.
- Do not use `nvfbheads=1` / removing `-nvkmsnosmooth` (reported for other Turing
  cards) on this configuration: it hangs at verbose boot. Keep `nvfbheads=4`
  and `-nvkmsnosmooth` as generated by 1401.

## Known behaviour on this configuration
- Desktop interactions (window drag, Mission Control, Dock magnification) are
  CPU-bound in WindowServer (≈100% of a core); cursor is smooth.
- Driver 2.5.4: display flicker observed after upgrade; 2.3.6 is stable for us.
- Sleeping is not recommended (issue #353).

## Recovery notes (macOS recovery)
- The Recovery volume created by macOS 15.8.1 may fail to boot on AMD platforms
  (`Err(0xE)` opening `usr/standalone/OS.dmg.root_hash`); using the BaseSystem
  recovery present on the OpenCore ESP works.
```
