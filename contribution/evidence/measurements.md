# 实测数据（原始）

采集环境：macOS 15.8.1，驱动 2.3.6（除注明外），显示 2080 Ti / DP / 2560×1440@165Hz。

## 1. WindowServer CPU 占用（`ps -o %cpu= -p $(pgrep -x WindowServer)`，1–2 秒采样）
| 状态 | 采样值 |
|---|---|
| 空闲（无交互） | 0.0 / 2.4 / 13.7（一次混合采样） |
| 拖动窗口 / Mission Control / Dock 动画期间 | **105.0, 115.7, 120.2, 123.0, 106.2**（单核百分比） |
| 另一段交互采样 | 13.7 / 23.1 / 24.6 / 28.0 / 12.4 |

结论（数据层面）：交互时 WindowServer 吃满约一个核心，光标仍流畅（硬件光标层）。

## 2. 刷新率/分辨率对比（用户主观 + 采样，驱动 2.3.6）
| 配置 | 拖窗口/动画卡顿 | 备注 |
|---|---|---|
| 2560×1440 @165Hz | 明显 | 默认 |
| 2560×1440 @120Hz | 无明显改善 | 主观 |
| 2560×1440 @60Hz | 无明显改善 | 主观 |
| 1920×1080 @165Hz | 无明显改善 | 主观 |

## 3. `debug.nvrmfb_flip_latch`（1 vs 2）
| 值 | 结果 |
|---|---|
| 1（默认） | 卡顿 |
| 2（opt-in 优化） | 无可感知改善 |

## 4. 驱动版本对比
| 版本 | 桌面 | 闪烁/抽搐 | 卡顿 | 备注 |
|---|---|---|---|---|
| 2.3.6 | 正常 | 无 | 有 | 已回退至此版本 |
| 2.5.4 | 正常 | **有**（画面内容不变时抖动/闪烁） | 有 | 2026-10-24 22:12 安装，22:42 回退 |

## 5. 参数试验（来自 issue #283 的 workaround）
| 改动 | 结果 |
|---|---|
| `nvfbheads=1` + 删除 `-nvkmsnosmooth` | **启动卡在 verbose 白字界面**，无法进系统；用救援入口 `1401: Start once without NVIDIA driver` 进入后改回 `nvfbheads=4` + `-nvkmsnosmooth` |

## 6. 其他观察
- 装驱动前（显示由核显 NootedRed 承担）：`/Library/Logs/DiagnosticReports/` 累计 **39 个 `Kernel_*.gpuRestart`**（单个会话内 20 个），桌面黑屏只剩鼠标。
- 装驱动并切换到 2080 Ti 显示后：上述 gpuRestart 不再新增；测试期间 `*.panic` 数量为 **0**。
- 2.5.4 期间：无 kernel panic；仅显示闪烁。
